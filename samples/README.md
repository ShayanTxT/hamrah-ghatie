# نمونهٔ ZIM برای تست / Sample ZIM for testing

`wikipedia_climate_change_mini.zim` (حدود ۱۴ مگابایت) یک آرشیو ZIM **واقعی**
و کوچک است که برای تست سریع خوانندهٔ ZIM و جستجوی تماممتن داخل برنامه
قرار داده شده است.

- منبع: [openzim/zim-testing-suite](https://github.com/openzim/zim-testing-suite)
  فایل `data/withns/wikipedia_en_climate_change_mini_2024-06.zim`
- محتوا: گزیدهای از مقالههای انگلیسی ویکیپدیا دربارهٔ تغییرات اقلیمی
  (۲۰٬۵۶۵ ورودی، ۳٬۸۲۱ مقاله، ۱۹ کلاستر Zstandard، نسخهٔ ZIM 5.0)
- مجوز محتوا: ویکیپدیا (CC BY-SA)؛ خود فایل تستی توسط پروژهٔ openZIM
  منتشر شده است.

## چطور امتحان کنم؟

1. برنامه را باز کن → تب **کتابخانهٔ آفلاین** → «وارد کردن فایل ZIM».
2. این فایل را انتخاب کن و بگو «کپی به data».
3. صبر کن تا ایندکس شود (چند ثانیه).
4. توی کادر جستجو بنویس `climate` یا `اقلیم` و نتیجهها را ببین.
5. دکمهٔ «جستجوی عنوان در ZIM» هم مستقیم روی عناوین مقالهها میگردد.

از خط فرمان هم میشود:

```bash
python -m pytest -q tests/test_zim_reader.py tests/test_library.py
```

## حذف از ریپو

اگر خواستی ریپو سبک باشد، این فایل را حذف کن؛ تستها بهطور خودکار
`skip` میشوند (فقط تست مربوط به همین فایل). تستهای ساختگی/واحد همچنان
اجرا میشوند.

> فایلهای ZIM واقعی ویکیپدیای فارسی/انگلیسی (۲۰۰ مگ تا ۱۴ گیگ) **جزو
> ریپو نیستند** و باید در مرحلهٔ آمادهسازی و وقتی اینترنت هست دانلود شوند؛
> لینکها و حجمها در [README.fa.md](../README.fa.md) و
> [README.en.md](../README.en.md) آمده است.
